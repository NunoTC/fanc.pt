# FANC Engenharia — fanc.pt

Site institucional estático, sem custos de alojamento.

## Publicar gratuitamente
1. Crie uma conta no GitHub.
2. Crie um repositório, por exemplo `fanc-site`.
3. Envie `index.html` e `style.css`.
4. Ative **Settings → Pages → Deploy from a branch → main / root**.
5. No painel do GitHub Pages, adicione o domínio personalizado `fanc.pt`.
6. No gestor do domínio, configure os DNS indicados pelo GitHub Pages.

## Email
O formulário abre o programa de email do visitante e tenta enviar para `geral@fanc.pt`.
Se o email da empresa tiver outro endereço, altere `geral@fanc.pt` no fim do `index.html`.

## Nota
O site não necessita de WordPress, base de dados ou servidor. Pode ser alojado gratuitamente.
